# OVI FARMS — Project Initialization Context

## 1. Project Overview
- **Project Name:** OVI FARMS Web Experience
- **Business Domain:** Luxury Farmhouse Plots & Managed Farmland Realty
- **Objective:** Build a high-converting, visually stunning, modern web application for OVI FARMS to showcase farmhouse plots, build investor confidence, provide interactive plot exploration, and drive qualified site visit bookings.
- **Repository Root:** `c:/Users/suraj/Desktop/OVIFARMS`

## 2. Key Objectives
1. **Premium Brand Positioning:** Establish OVI FARMS as the premier destination for green wealth, luxury weekend living, and managed agro-realty.
2. **Transparent Plot Discovery:** Allow prospective buyers to explore plot sizes, layout, pricing transparency, and availability.
3. **High-Conversion Lead Engine:** Capture high-intent leads via seamless site visit scheduling, instant WhatsApp connectivity, and gated master plan/brochure downloads.
4. **Trust & Legal Integrity:** Highlight clear titles, verified water/soil viability, gated security, and institutional development standards.

## 3. Technology Stack Selection
- **Frontend & Full-Stack Core:** Next.js (App Router, React 19)
- **Styling Architecture:** Vanilla CSS / CSS Modules with Design Tokens (`ui-ux-pro-max` Earth Luxury theme)
- **Persistence Layer:** Structured JSON Store with Atomic File Writes (`data/site-config.json`, `data/leads.json`)
- **Excel Export Engine:** `xlsx` (SheetJS) generating formatted `.xlsx` files
- **Media Uploads:** Next.js Route Handlers saving to `public/uploads/`
- **Performance Standard:** High-DPI (Retina/4K), Locked 60–120Hz GPU-accelerated micro-interactions
